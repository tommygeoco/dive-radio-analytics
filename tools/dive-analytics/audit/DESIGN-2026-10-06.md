system and skill, retrofit this dashboard onto it (extending the system where it did not cover a
dashboard's needs), gate it with an adversarial design critic that must reach 10/10, and remove
the Inflight widget.

## New lock

- **validate 1q2 design system** (drift tier, source inspection): `audit/ds-audit.mjs` (vendored
  from the skill) reports zero raw colors, off-scale sizes, off-grid spacing, off-scale radii,
  non-Geist fonts, uppercase, or decorative gradients/blur on `index.html` and `agents.html`;
  chart colors are read from the stylesheet tokens (no pasted palette); the Inflight widget stays
  gone.

## Visible changes the owners will notice

- Geist / Geist Mono everywhere (inlined Latin subsets, ~70 KB per page; nothing fetched).
- One blue only for things you can tap; green/red only for above/below typical; amber for fragile
  (was orange); the freshness dot is gray when current (was green).
- Episodes are no longer eight colors: the newest (or selected) episode is the white line/bar, the
  rest gray; hover lights any line. The carousel cards lost their color dots.
- Stacked views: YouTube channels are the rose pair, X accounts the neutral pair; the legend sits
  above the plot.
- `▲12%` / `▼12%` / `≈` became `+12%` / `−12%` / `typical`.
- Insight categories lost their hues (a word and a glyph remain); see the 2026-10-07 section for
  the card order.
- The feedback drill is a dialog on desktop and a bottom sheet on phones, with a segmented filter.
- Pages replaced the single scroll (2026-10-07, below).

## Owner directive 2026-10-07: pages, the same desktop and phone layouts

"Adopt the same desktop and mobile layouts and parse the single page into sections or nav item'd
pages, especially for mobile." The page is now the system's app shell in one file: a 76 px rail on
desktop and a floating tab bar on phones over four hash routes — Today (show health, latest episode,
share watched, latest feedback, a link row to Actions), Episodes (row → chart → pane, the order
validator 1k locks), Actions (What matters) and About. Every surface still renders on every state
change; a route only chooses what is on screen, so no number can differ between pages.

Presentation changes that came with it (no number, definition or store changed):

- **Selecting an episode is focus + context**, not the one-bar "solo" the owners chose 2026-08-23:
  the selected bar or line turns white and the rest stay on the scale in gray. A one-bar chart lost
  the comparison and left an empty plot (critic round 1, M8; system extension #18). Owners can ask
  for the solo back; it is one function.
- **Actions lead with the action:** each card shows the recommendation first, the finding under it as
  its reason, and the counting note behind "How this is counted". The old fold behind
  "Recommendation ▾" was a space choice of the 2026-08-22 density pass, not an owner directive.
- **Absence is silent in the pane:** a live cell or destination row with no reading is left out
  instead of saying "not available" (constitution addendum). Chart tooltips still name a missing
  reading, as validator 1j2/chart-hover requires.
- **Touch screens read the moments as a list** under the watch curve; the pins stay as markers (two
  moments seconds apart cannot both have fingertip-sized targets). Pointer and keyboard keep the pins.
- About is set as prose in nine titled sections with an "On this page" index; dates read "Sep 4".
- Deep links: `#episodes/e12` opens that episode; Back returns to where the reader was.
