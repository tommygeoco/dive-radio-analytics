# DESIGN-2026-10-06 — Smart Sharps design-system retrofit

Owner directive (2026-10-06): turn the Smart Sharps UI into a reusable desktop + mobile design
system and skill, retrofit this dashboard onto it (extending the system where it did not cover a
dashboard's needs), gate it with an adversarial design critic that must reach 10/10, and remove
the Inflight widget.

- **System:** `~/.claude/skills/smart-sharps-design-system/` (tokens, components, reference docs,
  `scripts/ds-audit.mjs` linter, `scripts/shoot.mjs` screenshots + computed-style census,
  `agents/design-system-critic.md`). Extensions added for this page are listed in its
  `reference/extensions.md` (focus + context charts, series pairs, gauge, state pills, delta tags,
  insight cards, quotes, carousel, single-page shell, long-form About, chart tooltip card).
- **No number, definition, store, or absence rule changed.** Every change is presentation:
  stylesheet, markup classes, chart colors and fonts, glyphs, copy that named colors.

## Locks re-written (same strictness, new design) — reasons

| Lock | Was | Now | Why |
|---|---|---|---|
| validate 1q page gutter | `--gap: 14px` / phone `10px` | `16px` / `12px` | The system's 4 px grid bans half steps (14, 10). |
| validate 1q card fills | `background: var(--s1)` / panel `var(--s2)` | `var(--surface-1)` + inset `--line` hairline; panel `transparent` | Token names are the system's; cards outline with an inset hairline (never a border, so the gutter is still exact). |
| validate 1q episode panel | panel padding `var(--gap)`, `.pgrid` gap `var(--gap)` of filled tiles | pane padding 0; `.pgrid` one hairline grid (`gap: 1px` over `--line`), cells surface-1 | "Never a card in a card": the old filled tiles inside a filled panel were nested cards. The pane is now the container (Smart Sharps' detail-pane metric block). |
| validate 1q carousel inset | `padding: 2px; margin: -2px …` | `padding: 8px; margin: -8px …` | The system's chip-row recipe: 8 px keeps 44 px hit areas and focus rings unclipped. |
| validate 1p tooltip text edge | `.tt { --chip: 15px; }` | `16px` (summary popup: `0px`) | 4 px grid; the all-episode summary rows have no swatch now. |
| audience-ui.test preview surface | `background: var(--s1); }` | `background: var(--surface-1); border-radius: var(--radius-2xl); box-shadow: inset 0 0 0 1px var(--line);` | Same rule (one surface like every card) on the new tokens. |
| linkedin.test "Original ↗" | the ↗ glyph | `Original` + an aria-hidden svg icon | ↗ is outside the Geist Latin subset; the link text and href rules are unchanged and still asserted. |

## New lock

- **validate 1q2 design system** (drift tier, source inspection): `audit/ds-audit.mjs` (vendored
  from the skill) reports zero raw colors, off-scale sizes, off-grid spacing, off-scale radii,
  non-Geist fonts, uppercase, or decorative gradients/blur on `index.html` and `agents.html`;
  chart colors are read from the stylesheet tokens (no pasted palette); the Inflight widget stays
  gone.

## Visible changes the owners will notice

- Geist / Geist Mono everywhere (inlined Latin subsets, ~70 KB per page; nothing fetched).
- One blue only for things you can tap; green/red only for above/below typical; amber for fragile
  (was orange); the freshness dot is gray when current (was green).
- Episodes are no longer eight colors: the newest (or selected) episode is the white line/bar, the
  rest gray; hover lights any line. The carousel cards lost their color dots.
- Stacked views: YouTube channels are the rose pair, X accounts the neutral pair; the legend sits
  above the plot.
- `▲12%` / `▼12%` / `≈` became `+12%` / `−12%` / `typical`.
- Insight categories lost their hues (a word and a glyph remain); recommendations open as a hairline
  strip under a "Recommendation" link button.
- The feedback drill is a dialog on desktop and a bottom sheet on phones, with a segmented filter.
- Section titles "Episodes" and "What matters"; "About this data" is a disclosure row.
